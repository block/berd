# Berd Telemetry

Telemetry is disabled by default in official Berd distributions. If you enable it, Block collects a random installation identifier and limited predefined usage events to operate and improve Berd. Telemetry excludes prompts, messages, files, source code, credentials, names, emails, and IP addresses, although Block and its service providers process IP addresses for transmission, security, and rate limiting.

You may disable telemetry at any time in Berd’s settings. For more information about Block’s privacy practices and your rights, see the [Berd Privacy Notice](https://berd.xyz/sites/berd/privacy.html).  Third-party distributions or forks may modify, remove, or redirect the telemetry feature and may follow different practices. Review the documentation and source code provided by the distributor of your build.
